# 🔧 Engineering Thermal Process Calculator (C++ / Qt)

A desktop engineering tool that models thermodynamic heat transfer calculations using C++ and Qt.  
Designed to simulate real-world industrial calculation software used in engineering environments.

---

## 📌 Overview

This application calculates heat energy required for temperature changes in different materials using fundamental thermodynamic principles.

It was built to demonstrate:
- Engineering problem-solving in software
- Structured C++ development
- GUI application design using Qt
- Clean, maintainable architecture

---

## ⚙️ Core Formula

Q = m × c × ΔT

Where:
- Q = Heat Energy (Joules)
- m = Mass (kg)
- c = Specific Heat Capacity (J/kg°C)
- ΔT = Temperature Change (°C)
